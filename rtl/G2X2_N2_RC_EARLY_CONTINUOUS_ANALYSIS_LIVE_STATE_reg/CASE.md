# G2X2 N2 RC EARLY Continuous Analysis Live State

`CASE_ID: G2X2_N2_RC_EARLY_CONTINUOUS_ANALYSIS_LIVE_STATE_reg`

This isolated policy-engine variant consumes one caller-owned 272-bit live
analyzer projection for the current serial SA. It does not contain an
analyzer-state bank or a selected-solution payload register. The frozen
canonical analyzer and selected-address mux remain external source
dependencies.
